# Daniel Generation School

Official website for Daniel Generation School (DGS), a Cambridge-curriculum Christian school in Kigali, Rwanda.

🌐 **Live site:** https://danielgenerationschool.rw

## Tech Stack
- React + TypeScript
- Vite
- Tailwind CSS
- Framer Motion
- i18next (EN/FR)
- EmailJS

## Pages
- Home
- Founder
- Facilities
- Core Values
- FAQ
- Contact
- Calendar
- News

## Run Locally
```bash
npm install
npm run dev
```

## Deploy
Deployed automatically via Vercel on every push to `main`.
